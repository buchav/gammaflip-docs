## 1. Get access

Sign up at [gammaflip.io](https://gammaflip.io). You get a 14-day trial with
API access included (50 requests/day). Plans with API access get 500
requests/day and up to 5 keys; see [Authentication](/authentication).

## 2. Create an API key

1. Log in at [gammaflip.io/account](https://gammaflip.io/account)
2. Open the menu → **API Keys**
3. Click **Create API Key**, give it a description
4. Copy the key — it's shown only once

<Warning>
Your API key starts with `gex_sk_` and is shown **only once** at creation.
Save it somewhere secure (password manager, env var). If you lose it, you'll
need to create a new one.
</Warning>

## 3. Make your first request

List available exchanges (free: discovery calls don't count against your quota):

<CodeGroup>

```bash cURL
curl https://api.gammaflip.io/api/v1/exchanges \
  -H "X-API-Key: gex_sk_your_key_here"
```

```python Python
import requests

resp = requests.get(
    "https://api.gammaflip.io/api/v1/exchanges",
    headers={"X-API-Key": "gex_sk_your_key_here"},
)
print(resp.json())
```

```javascript Node.js
const resp = await fetch("https://api.gammaflip.io/api/v1/exchanges", {
  headers: { "X-API-Key": "gex_sk_your_key_here" },
});
console.log(await resp.json());
```

</CodeGroup>

Expected response:

```json
{
  "data": {
    "available": ["bybit", "deribit", "okx", "derive", "tradfi"],
    "virtual": ["all"],
    "markets": {
      "crypto": ["deribit", "bybit", "okx", "derive"],
      "tradfi": ["tradfi"]
    }
  },
  "meta": {
    "timestamp": "2026-10-06T10:00:00+00:00"
  }
}
```

## 4. Get real GEX data

Fetch the GEX term structure for Bitcoin across all exchanges:

<CodeGroup>

```bash cURL
curl https://api.gammaflip.io/api/v1/gex/term-oi/all/BTC \
  -H "X-API-Key: gex_sk_your_key_here"
```

```python Python
resp = requests.get(
    "https://api.gammaflip.io/api/v1/gex/term-oi/all/BTC",
    headers={"X-API-Key": "gex_sk_your_key_here"},
)
data = resp.json()["data"]
for exp in data["expirations"]:
    print(exp["date"], exp["total_gex"], exp["total_oi"])
```

</CodeGroup>

## 5. Get the key levels in one call

`/levels` returns a small flat object (flip, regime, walls, totals) for the
latest snapshot. Try a US ticker:

```bash
curl https://api.gammaflip.io/api/v1/levels/tradfi/QQQ \
  -H "X-API-Key: gex_sk_your_key_here"
```

Every response says how fresh it is (`meta.as_of`, `meta.oi_as_of`). Field
definitions are in the [data dictionary](/data-dictionary).

## 6. Check your rate limit

Counted responses (`/gex/...`, `/levels/...`) include these headers:

```
X-RateLimit-Limit: 500
X-RateLimit-Remaining: 498
X-RateLimit-Reset: 2026-04-15T00:00:00+00:00
```

When you hit the limit, you'll get `429 Too Many Requests` (with no
`Retry-After` header; use `X-RateLimit-Reset`). Quota resets at **midnight UTC**
every day. [`GET /me`](/api-reference/me) shows your quota for free.

<Tip>
The underlying GEX data updates every 15 minutes (from our Lambda capture).
Polling more frequently than that doesn't yield new data.
</Tip>
