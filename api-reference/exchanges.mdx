---
title: 'List Exchanges'
api: 'GET /exchanges'
description: 'Returns available exchanges grouped by market. Free: not counted against the quota'
---

## Response

<ResponseField name="data.available" type="array">
  List of exchange names currently online and queryable. Supported:
  `bybit`, `deribit`, `okx`, `derive` and `tradfi`.
</ResponseField>

<ResponseField name="data.markets" type="object">
  The same exchanges split by market: `{"crypto": [...], "tradfi": ["tradfi"]}`.
  Crypto venues are in canonical order.
</ResponseField>

<ResponseField name="data.virtual" type="array">
  List of virtual exchanges. Currently just `["all"]`: a cross-exchange
  aggregator for crypto coins (for TradFi tickers `all` is an alias of `tradfi`).
  You can also request a subset of crypto venues with `+`, for example
  `deribit+derive`. See [Markets and exchanges](/markets-and-exchanges).
</ResponseField>

<ResponseField name="meta.timestamp" type="string">
  ISO 8601 timestamp of when the response was generated.
</ResponseField>

<Note>
This endpoint is free and does not count against your quota, so there is no
`rate_limit` block or `X-RateLimit-*` header. Use [`/me`](/api-reference/me)
to see your quota.
</Note>
