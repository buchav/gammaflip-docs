---
title: 'List Expirations'
api: 'GET /expirations/{exchange}/{coin}'
description: 'Returns sorted, non-expired option expirations with ISO date, DTE and cutoff. Free: not counted against the quota'
---

## Path parameters

<ParamField path="exchange" type="string" required>
  Crypto: `bybit`, `deribit`, `okx`, `derive`, `all` / `combined`, or a subset
  such as `deribit+derive`. TradFi tickers: `tradfi` (`all` and `combined` are
  aliases). See [Markets and exchanges](/markets-and-exchanges).
</ParamField>

<ParamField path="coin" type="string" required>
  Symbol, for example `BTC` or `QQQ`. Case-insensitive. Use `/coins` to see what's available.
</ParamField>

## Response

<ResponseField name="data.expirations" type="array">
  Array of expiration date strings in `DDMMMYY` format (e.g., `25APR26`),
  sorted chronologically. Already-expired dates are filtered out. The cutoff is
  08:00 UTC for crypto and 16:00 US Eastern for TradFi, each with a 1-hour grace
  period.
</ResponseField>

<ResponseField name="data.expirations_detail" type="array">
  One object per entry of `expirations`, in the same order:

  - `code`: the `DDMMMYY` code
  - `iso`: the expiration date as `YYYY-MM-DD`
  - `dte`: days to the cutoff, as a decimal (two places)
  - `cutoff_utc`: the cutoff instant, ISO 8601 UTC with `Z`
  - `is_0dte`: `true` when the expiration is today (in the market's own time zone)

  Path parameters elsewhere accept either the code or the ISO date.
</ResponseField>

<ResponseField name="meta.exchange" type="string">
  The exchange you queried (echoed back).
</ResponseField>

<ResponseField name="meta.coin" type="string">
  The coin you queried (echoed back).
</ResponseField>

<ResponseField name="meta.exchange_resolved" type="string">
  The canonical venue after aliasing, for example `tradfi` for `all/QQQ` or
  `deribit+derive` for a subset.
</ResponseField>

<ResponseField name="meta.market" type="string">
  `crypto` or `tradfi`.
</ResponseField>

## Errors

<ResponseField name="400 invalid_exchange / invalid_pair" type="error">
  Exchange name isn't recognized, or it does not match the coin's market. The
  body includes `valid_exchanges`.
</ResponseField>

<RequestExample>

```bash cURL
curl https://api.gammaflip.io/api/v1/expirations/all/BTC \
  -H "X-API-Key: gex_sk_your_key_here"
```

```python Python
import requests

resp = requests.get(
    "https://api.gammaflip.io/api/v1/expirations/all/BTC",
    headers={"X-API-Key": "gex_sk_your_key_here"},
)
for exp in resp.json()["data"]["expirations"]:
    print(exp)
```

</RequestExample>
