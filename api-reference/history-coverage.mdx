---

## What it returns

One row per exchange and symbol that has stored history: when it starts and ends,
how many sessions it spans and which daily files are available. Use it before a
backfill to see, for example, that a symbol's history starts in May instead of
guessing.

This endpoint is **free**: it does not count against your request quota. The
result is cached for up to an hour.

## Response

<ResponseField name="data" type="array">
  One object per `(exchange, symbol)`:

  <Expandable title="fields">
    <ResponseField name="exchange" type="string">
      `bybit`, `deribit`, `okx`, `derive`, `combined` or `tradfi`.
    </ResponseField>
    <ResponseField name="symbol" type="string">
      For example `BTC`, `QQQ`.
    </ResponseField>
    <ResponseField name="first_ts" type="string">
      First stored capture, ISO 8601 UTC `Z`.
    </ResponseField>
    <ResponseField name="last_ts" type="string">
      Latest stored capture, ISO 8601 UTC `Z`.
    </ResponseField>
    <ResponseField name="sessions" type="integer">
      Number of distinct session dates with at least one capture.
    </ResponseField>
    <ResponseField name="files_first_date" type="string | null">
      First session date with a [daily file](/api-reference/history-files);
      `null` when no file has been built yet.
    </ResponseField>
    <ResponseField name="files_last_date" type="string | null">
      Latest session date with a daily file; `null` when none.
    </ResponseField>
  </Expandable>
</ResponseField>
