---
title: 'List Coins'
api: 'GET /coins'
description: 'Returns available symbols across all exchanges, split by market. Free: not counted against the quota'
---

## Response

<ResponseField name="data.coins" type="array">
  Sorted list of base coin symbols (uppercase) that have options listed on at
  least one supported exchange.

  Typical values: `BTC`, `ETH`, `SOL`, `XRP`, and TradFi tickers such as `SPX`,
  `SPY`, `QQQ`.
</ResponseField>

<ResponseField name="data.markets" type="object">
  The same symbols split by market: `{"crypto": [...], "tradfi": [...]}`. The
  market decides which `{exchange}` values are valid for a symbol. See
  [Markets and exchanges](/markets-and-exchanges).
</ResponseField>

<Note>
This endpoint is free and does not count against your quota.
</Note>

<RequestExample>

```bash cURL
curl https://api.gammaflip.io/api/v1/coins \
  -H "X-API-Key: gex_sk_your_key_here"
```

```python Python
import requests

resp = requests.get(
    "https://api.gammaflip.io/api/v1/coins",
    headers={"X-API-Key": "gex_sk_your_key_here"},
)
coins = resp.json()["data"]["coins"]
print(f"Available coins: {', '.join(coins)}")
```

</RequestExample>
