api: 'GET /gex/by-strike-enhanced/{exchange}/{coin}/{expiration}'
description: 'GEX data by strike price with key markers (gamma flip, max pain, walls) and aggregate totals'
---

## What it returns

For a specific expiration, this endpoint returns:

- **GEX per strike** — call, put, net, and total dealer gamma exposure at each listed strike
- **Key markers** — gamma flip point, max pain, largest positive/negative GEX strikes (walls),
  max-volatility and max-stability price levels, spot reference, and aggregate totals
- **Asymmetry metrics** — upside vs. downside GEX imbalance and bias direction
- **Metadata** — current price, strike range, timestamp, exchange/coin/expiration
- **Levels** — a flat `levels` object (flip, regime, walls, totals, max pain, ATM IV),
  defined in the [data dictionary](/data-dictionary). The same object is returned on its own by
  [`/levels`](/api-reference/levels)

This is the most detailed GEX endpoint — it's what powers the "GEX by Strike"
chart on [gammaflip.io](https://gammaflip.io).

## Path parameters

<ParamField path="exchange" type="string" required>
  Crypto: `bybit`, `deribit`, `okx`, `derive`, `all` / `combined`, or a subset
  such as `deribit+derive`. TradFi tickers: `tradfi` (`all` and `combined` are
  aliases). See [Markets and exchanges](/markets-and-exchanges).
</ParamField>

<ParamField path="coin" type="string" required>
  Symbol, for example `BTC`, `ETH`, `QQQ`. Case-insensitive.
</ParamField>

<ParamField path="expiration" type="string" required>
  Expiration date in `DDMMMYY` format (e.g., `25APR26`), as an ISO date
  (`2026-04-25`), or `TOTAL` to combine all expirations into a single view.
</ParamField>

## Query parameters

<ParamField query="view" type="string" default="full">
  `full` (default, unchanged) returns the per-strike arrays, markers and
  metadata. `levels` returns only `levels` and `metadata`: a compact answer
  for scripts and LLM agents (a full `TOTAL` payload is tens of KB). Any other
  value returns `400 invalid_param` with `valid_values`.
</ParamField>

<ParamField query="range_pct" type="number">
  With `view=full`, keeps only strikes within ±`range_pct` % of spot in the
  per-strike arrays. Must be in (0, 50]; otherwise `400 invalid_param` with
  `max_value: 50`. Without it, you get the full strike range as before. It has no
  effect with `view=levels`, which has no per-strike arrays.
</ParamField>

### Field guide

- **`gex_data`** — parallel arrays; index `i` across all arrays refers to the same strike.
  `total_gex` = `call_gex - put_gex` aggregated on dealers' side.
- **`flip_points`** — price level(s) where net dealer GEX crosses zero. Above the flip,
  dealer hedging is positive-gamma (stabilising); below, it's negative-gamma (amplifying).
- **`absolute_max` / `positive_max` / `negative_max`** — ranked lists of the largest absolute,
  positive, and negative GEX strikes. These are the "walls" where hedging flows concentrate.
- **`stability_point`** — max-stability level: the peak of the net-gamma profile (a price, not a strike).
- **`volatility_point`** — max-volatility level: the trough of the net-gamma profile (a price, not a strike).
- **`asymmetry`** — imbalance between upside and downside dealer exposure; `bias` is
  a qualitative read (`bullish` / `bearish` / `neutral`).

<Info>
`TOTAL` aggregates all expirations for the given coin. Useful for getting an
"all-positioning" view; individual expiration views are more precise for
timing-specific trades.
</Info>

## Response meta

Every data response (this endpoint, [`/levels`](/api-reference/levels) and
[term-oi](/api-reference/term-oi)) carries a self-describing `meta`. The keys
below are additive: `meta.exchange`, `meta.coin` and `meta.expiration` keep their
existing values.

| Field | Meaning |
|-------|---------|
| `as_of` | Time the data reflects. ISO 8601 UTC with `Z`, second precision |
| `oi_as_of` | Session date (`YYYY-MM-DD`) of the open interest used. TradFi open interest settles once a day, so intraday it is the previous session |
| `data_source` | `live`, `eod`, … (crypto is always `live`) |
| `is_live` | `true` when the data is a live snapshot |
| `market_open` | Whether the market is open (always `true` for crypto) |
| `next_open` | Next market open (TradFi); `null` for crypto |
| `units` | `"USD per 1% move of the underlying"` |
| `docs_url` | Link to the [data dictionary](/data-dictionary) |
| `exchange_resolved` | Canonical venue after aliasing: `tradfi`, `deribit`, `combined`, `deribit+derive`, … |
| `market` | `crypto` or `tradfi` |
| `symbol` | The symbol queried (same as `coin`) |
| `expiration_iso` | The expiration as `YYYY-MM-DD` (`null` for `TOTAL`) |

`meta.timestamp` is when the response was generated. `meta.rate_limit` shows your
quota (this call counts as 1 request).

## Errors

<ResponseField name="400 invalid_exchange / invalid_pair" type="error">
  Exchange not recognized, or it does not match the coin's market. The body
  includes `valid_exchanges`.
</ResponseField>

<ResponseField name="400 invalid_expiration" type="error">
  The expiration is not listed. The body includes `nearest_expirations`
  (up to five ISO dates closest to the one you sent, or the earliest five if the value is not a date).
</ResponseField>

<ResponseField name="400 invalid_param" type="error">
  `view` or `range_pct` is invalid. The body includes `valid_values` or `max_value`.
</ResponseField>

<ResponseField name="403 market_not_in_plan" type="error">
  Your plan does not include this coin's market. The body includes `markets_in_plan`.
</ResponseField>

<ResponseField name="403 market_not_in_plan" type="error">
  The coin belongs to a market your plan doesn't cover. See
  [market_not_in_plan](/errors#market_not_in_plan-403).
</ResponseField>

<ResponseField name="404 no_data" type="error">
  No data for this coin/exchange/expiration combination. Common cause: the
  expiration doesn't exist on that exchange (use `/expirations/` first).
</ResponseField>

<RequestExample>

```bash cURL
curl "https://api.gammaflip.io/api/v1/gex/by-strike-enhanced/all/BTC/25APR26" \
  -H "X-API-Key: gex_sk_your_key_here"
```

```python Python
import requests

resp = requests.get(
    "https://api.gammaflip.io/api/v1/gex/by-strike-enhanced/all/BTC/25APR26",
    headers={"X-API-Key": "gex_sk_your_key_here"},
)
data = resp.json()["data"]

markers = data["markers"]
meta = data["metadata"]

print(f"Spot:          {meta['current_price']:,.2f}")
if markers["flip_points"]:
    print(f"Gamma flip:    {markers['flip_points'][0]['strike']:,.2f}")
print(f"Max volatility:{markers['volatility_point']['price']:,.2f}")
print(f"Max stability: {markers['stability_point']['price']:,.2f}")
print(f"Net GEX:       {markers['totals']['net_gex']:+,.0f}")
print(f"Bias:          {markers['asymmetry']['bias']}")

# Top 5 strikes by absolute GEX
gex = data["gex_data"]
rows = sorted(
    zip(gex["strikes"], gex["net_gex"]),
    key=lambda r: abs(r[1]),
    reverse=True,
)
for strike, net in rows[:5]:
    print(f"Strike {strike:>8,.0f}: net GEX = {net:+,.0f}")
```
