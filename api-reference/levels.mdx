## What it returns

One flat object describing the latest GEX snapshot: spot, the primary gamma flip,
the dealer regime, the largest positive / negative / absolute GEX strikes,
net and absolute totals, the stability and volatility levels, max pain and ATM
implied volatility. No per-strike arrays, so the response is small, which makes
this the first call for a script or an LLM agent.

Costs **1 request** against your [daily quota](/rate-limits). Field definitions,
units and sign convention are in the [data dictionary](/data-dictionary).

## Path parameters

<ParamField path="exchange" type="string" required>
  Crypto: `bybit`, `deribit`, `okx`, `derive`, `all` / `combined`, or a subset
  such as `deribit+derive`. TradFi tickers: `tradfi` (`all` and `combined` are
  aliases). See [Markets and exchanges](/markets-and-exchanges).
</ParamField>

<ParamField path="coin" type="string" required>
  Symbol, for example `BTC`, `ETH`, `QQQ`, `SPX`. Case-insensitive. Use
  [`/coins`](/api-reference/coins) to see what is available.
</ParamField>

## Query parameters

<ParamField query="expiration" type="string" default="TOTAL">
  `TOTAL` (all expirations combined), an expiration code such as `17OCT26`, or an
  ISO date such as `2026-10-17`. `max_pain` is `null` for `TOTAL`.
</ParamField>

<ParamField query="compare" type="string">
  Comma-separated list of `1d`, `7d` and `30d`. Adds `data.compare`: for each period,
  the last stored capture on or before the session date N days ago, with the deltas
  to the live levels. Available for `TOTAL` only (otherwise `400 invalid_param`).
  Venue subsets have no history and return `400 history_not_available`. See
  [Compare with the past](#compare-with-the-past).
</ParamField>

## Response

<ResponseField name="data" type="object">
  The levels fields (`spot`, `flip`, `flip_count`, `regime`, `net_gex`,
  `abs_gex`, `call_gex`, `put_gex`, `call_oi_total`, `put_oi_total`,
  `p1_strike` … `a2_gex`, `s_price`, `s_gex`, `v_price`, `v_gex`, `max_pain`,
  `atm_iv`) plus `expiration` (`TOTAL` or the code) and `expiration_iso`
  (`YYYY-MM-DD`, `null` for `TOTAL`). Missing values are `null`.
</ResponseField>

<ResponseField name="meta" type="object">
  Freshness and context: `as_of`, `oi_as_of`, `data_source`, `is_live`,
  `market_open`, `next_open`, `units`, `docs_url`, `exchange_resolved`,
  `market`, `symbol`, plus the echoed `exchange`, `coin`, `expiration` and
  `expiration_iso`, and your `rate_limit`.
  See [Response meta](/api-reference/by-strike-enhanced#response-meta).
</ResponseField>

## Compare with the past

`?compare=1d,7d,30d` answers "what changed since" in one call. `data.compare` has
one key per requested period. Each value is either `null` (no history that far
back) or a history row with the fields of
[`/history/levels`](/api-reference/history-levels) (`timestamp_utc`,
`session_date`, `type`, `oi_date`, `spot`, `flip`, `regime`, ...) plus a `delta`
object: the live value minus the past value for `spot`, `flip`, `net_gex`,
`abs_gex`, `p1_strike`, `n1_strike`, `s_price` and `v_price` (`null` when either
side is missing).

- The reference date is today minus N days in the market's session calendar: the
  UTC date for crypto, the **New York date** for TradFi. The row returned is the
  last capture of the latest session on or before that date, so a weekend
  reference gives Friday's close. Check its `session_date`.
- `type` is `close` only when that session is complete.
- If the history lookup fails the live levels are still returned, with every period `null`.

```json
"compare": {
  "1d": {
    "timestamp_utc": "2026-10-05T20:15:00Z", "session_date": "2026-10-05",
    "type": "close", "oi_date": "2026-10-02", "spot": 751.2, "flip": 742.0,
    "regime": "positive", "net_gex": 2100000000.0, "...": "...",
    "delta": { "spot": 4.6, "flip": 2.59, "net_gex": 280000000.0, "abs_gex": 310000000.0,
               "p1_strike": 0, "n1_strike": 0, "s_price": 0.0, "v_price": 0.0 }
  },
  "7d": null
}
```

Illustrative values, shortened. It does not add to the request cost: still 1 request.

## Errors

<ResponseField name="400 invalid_exchange / invalid_pair" type="error">
  Unknown venue, or a venue that does not match the coin's market. The body
  includes `valid_exchanges`.
</ResponseField>

<ResponseField name="400 invalid_expiration" type="error">
  The expiration is not listed. The body includes `nearest_expirations` (up to five ISO dates closest to the one you sent, or the earliest five if the value is not a date).
</ResponseField>

<ResponseField name="400 invalid_param / history_not_available" type="error">
  With `compare`: a period other than `1d`, `7d`, `30d` (`valid_values`), a
  single expiration instead of `TOTAL`, or a venue subset (`valid_exchanges`).
</ResponseField>

<ResponseField name="403 market_not_in_plan" type="error">
  Your plan does not include this coin's market. The body includes
  `markets_in_plan`.
</ResponseField>

<ResponseField name="404 no_data" type="error">
  No snapshot for this combination.
</ResponseField>

<RequestExample>

```bash cURL
curl https://api.gammaflip.io/api/v1/levels/tradfi/QQQ \
  -H "X-API-Key: gex_sk_your_key_here"
```

```python Python
import requests

resp = requests.get(
    "https://api.gammaflip.io/api/v1/levels/tradfi/QQQ",
    headers={"X-API-Key": "gex_sk_your_key_here"},
)
body = resp.json()
lv, meta = body["data"], body["meta"]
print(f"{meta['symbol']} spot {lv['spot']} flip {lv['flip']} regime {lv['regime']}")
print("as of", meta["as_of"], "| OI as of", meta["oi_as_of"])
```

```javascript Node.js
const resp = await fetch("https://api.gammaflip.io/api/v1/levels/tradfi/QQQ", {
  headers: { "X-API-Key": "gex_sk_your_key_here" },
});
const { data, meta } = await resp.json();
console.log(data.regime, data.flip, meta.as_of);
```

<Note>
The values above are illustrative (a TradFi snapshot taken during the US session).
`max_pain` is `null` because this call is for `TOTAL`; pass a single expiration
to get it. When the market is closed, `data_source` and `is_live` say whether the
snapshot is live or end-of-day, and `next_open` carries the next open.
</Note>
